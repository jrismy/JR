# 人工智能编年史 · Chronicle of AI

一个讲解人工智能历史的单页网站（1950—2026）：八章、两次寒冬、四十余个年份条目，
以中文编年史的视觉语言呈现——宣纸灰白 × 青墨 × 朱砂印章，竖排章题，滚动时左栏实时显示「当前纪年」。

## 使用

纯静态、零依赖，直接在浏览器打开 `index.html` 即可；亦可部署到任意静态托管（GitHub Pages 等）。

## 特性

- 首屏「年代标尺」可点击跳转对应章节，灰段标出两次 AI 寒冬
- 左侧书脊栏：章节目录高亮 + 随滚动跳动的当前年份
- 深浅双主题：跟随系统，亦可点击「昼 / 夜」手动切换（记忆偏好）
- 里程碑条目盖朱砂小印；寒冬章节整体降温为钢灰色调
- 响应式布局，尊重 `prefers-reduced-motion`
