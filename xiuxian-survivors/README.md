# 修仙幸存者 · 万妖夜行

类幸存者（Survivors-like）修仙题材游戏。Canvas 2D，不用 WebGL、不用引擎、不用任何外部图片与音频——全部美术由代码生成，全部音效与 BGM 由 Web Audio 实时合成。

## 运行

```bash
npm install
npm run dev     # 开发
npm run build   # 生产构建 → dist/
```

代码是原生 ES Modules，也可以不经构建直接用任意静态服务器打开 `index.html`（如 `python3 -m http.server`）。

## 操作

- 桌面：WASD / 方向键移动，攻击全自动；P 暂停；F3 调试面板（fps/实体数/粒子数/画质档）
- 移动端：竖屏自适应，按住屏幕出现虚拟摇杆

## 渲染管线（动态水墨 × 灵光辉映）

五层离屏合成：

| 层 | 内容 |
|---|---|
| L0 环境 | 视差水墨山峦剪影（0.15x/0.35x/0.5x）+ 漂移雾带 |
| L1 地面 | 笔触纹理网格 + 持久痕迹层（雷击焦痕/青莲灼印/冰霜残迹低频衰减） |
| L2 实体 | 敌人 / 玩家 / 子弹 / 普通混合粒子 |
| L3 辉光 | `lighter` 叠加，0.5x 分辨率渲染后放大——画面"仙气"的来源 |
| L4 后期 | 暗层光照（destination-out 冲光圈）、色调分级、暗角、红/金/白闪、雷击单帧色差 |

其余：预烘焙贴图（光斑/剑形/冰棱/八卦/太极/莲花，运行时零渐变创建）、条带式拖尾（首宽尾窄三角条带）、递归分叉雷电、统一 `timeScale`（震屏/顿帧/慢动作/缩放冲击）、对象池 + 空间哈希碰撞 + 视口剔除、`devicePixelRatio` 上限 2、近 5 秒帧率采样自动降档（极/高/中，可手动锁定）。

## 玩法

- **角色**：剑尘子（御剑，伤害+15%）/ 紫电真人（天雷，冷却-15% 移速+8%）/ 玄岳居士（罡气，+50血+回血，移速-8%）
- **模式**：证道之途（20分钟天劫结局）/ 无尽妖渊 / 修罗炼狱（敌强灵气多）
- **境界**：炼气→…→真仙十大境界各九层，跨大境界触发突破演出并觉醒神通（护盾/震爆/元婴/领域/剑雨/合一/链电/不死金身/仙威）
- **武器**：十七种功法各 7–8 重，重数带视觉质变（✦ 标注）——御剑/环身/天雷/罡气/真火/寒冰/鬼火七式经典，另有离火符、瑶琴音杀、流转念珠、镇岳玉印、缚灵青藤、星火流石、太阴月轮、御灵木傀、噬灵漩涡、梵音金钟十式新传；经典七式满重 + 对应心法≥3 重解锁七大**禁术**（金框卡+全屏演出）
- **心法**：十六诀各五重（攻防/暴击/范围/经验/反伤/闪避等）；全部悟尽后出**道果**无限兜底，任何时刻升级必有三张卡
- **事件**：每 60 秒妖王（黑边出场+泼墨名号+必掉宝箱）、每 150 秒妖潮环形包围、第 18 分钟天劫警告、第 20 分钟天劫化身（环形弹幕/突进/召唤）→ 斩杀后飞升演出 + B/A/S/SS 评级
